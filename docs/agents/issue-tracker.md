# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues in `lunalhx/Kiln-AI`. Use the `gh` CLI for tracker operations from this clone so the repository is inferred from `origin`.

## Conventions

- Create an issue with `gh issue create --title "..." --body-file <path>`.
- Read an issue and its labels with `gh issue view <number> --comments`.
- Apply triage labels with `gh issue edit <number> --add-label "..."`.
- Close an issue with `gh issue close <number> --comment "..."`.
- Publishing a Spec means creating a GitHub issue.

## Pull requests as a triage surface

PRs as a request surface: no.
