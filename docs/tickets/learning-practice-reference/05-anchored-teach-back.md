# 05 — 锚定的 Teach-back 切片

**What to build:** 学习者在同一 Learning Flow 内暴露 Explain worked example 或 H5 reveal 后，可提交一个锚定的短文本 Teach-back，并在通过时获得 understanding Evidence。

**Blocked by:** 03 — Explain Profile 的完整教学切片; 04 — Apply Practice 的持久化 Hint Ladder.

**Status:** done

- [x] Guard 仅在最近的合格 Explain/H5 artifact 存在时提供 Teach-back；生成的短文本 Task 经过独立验证并仅允许一次正式提交。
- [x] 规则识别、适用性解释、步骤和结果连贯性三个 Rubric 维度均通过才算 PASS；PASS/FAIL 产生 understanding Evidence，Inconclusive 产生 fresh replacement 而不产生 Evidence。
- [x] Teach-back 不支持 Hint，且其 PASS 不满足 Apply Practice readiness。
