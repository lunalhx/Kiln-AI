# 08 — “已知” prerequisite 的代表性 readiness check

**What to build:** 对未能走 Progress 快路径而声称 `known` 的学习者，系统交付一项小型、无 assistance 的代表性 prerequisite task，并根据其结果继续 Diagnostic 或返回安全推荐。

**Blocked by:** 07 — 版本对齐的 prerequisite Progress 快路径.

**Status:** ready-for-agent

- [ ] `known` 自我报告本身不建立 readiness；仅允许一项由 Plan 授权、预先生成、Gate 并验证的代表性 prerequisite task，默认不启用 rationale。
- [ ] 正向确认仅创建 Flow-scoped prerequisite readiness，随后进入依赖顺序中的下一个 Required Supporting Concept 或 Target Diagnostic；不创建 Supporting Concept Evidence、milestone 或 review。
- [ ] Conclusive 结果或 terminal Unconfirmed 结果停止 probing 并展示相应的 Prerequisite Learning Recommendation；Unconfirmed 不得作为 learner failure 或 deficit claim。
- [ ] 该 task 的生成、Attempt close、Finding/readiness 与下一 interaction 原子提交；replay/recovery 不重复 task、Finding、recommendation 或后续 Target interaction，且公开投影维持隐私边界。
