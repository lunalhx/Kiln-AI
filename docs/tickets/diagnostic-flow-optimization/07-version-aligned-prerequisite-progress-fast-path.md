# 07 — 版本对齐的 prerequisite Progress 快路径

**What to build:** 已有且版本对齐的 Independent 或 Durable Supporting Concept Progress 直接建立 prerequisite readiness，让学习者跳过不必要的检查并继续 Target Diagnostic。

**Blocked by:** 03 — 有界的多 Attempt Target Readiness 覆盖; 06 — Prerequisite 推荐与显式 Supporting Flow 启动.

**Status:** ready-for-agent

- [ ] 只有 Supporting Concept identity、Mastery Rubric、Mastery Criterion 与 source basis 全部对齐的 Independent 或 Durable Progress 才能跳过 prerequisite check，并继续下一个 prerequisite 或 Target Diagnostic。
- [ ] 缺失、较低、外部取得或任一相关版本不匹配的 Progress 必须进入既有 Prerequisite Readiness Check；不得被当作 readiness 或降级为默认通过。
- [ ] 跨 Flow 协调只读取已提交、版本对齐的 Concept Progress 与 Target-to-Supporting 引用，不读取另一 Flow 的 raw response、Blackboard、prompt、evaluator output 或 Diagnostic Finding。
- [ ] whole-flow contract、公共 API/参考 UI 和重放测试验证跳过与 recheck 的 learner-visible 路径，且不会创建 Supporting Concept Evidence、milestone 或 review。
