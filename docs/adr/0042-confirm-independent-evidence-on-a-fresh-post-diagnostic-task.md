# Confirm independent evidence on a fresh post-diagnostic task

A no-hint Diagnostic Finding may contribute to showing that a learner is ready to demonstrate a Target Concept, but it never directly establishes Independent and an individual passing Attempt does not by itself end a multi-Attempt Diagnostic. Kiln-AI will generate a fresh equivalent Independent Test only when the Diagnostic Routing Decision confirms all Required Supporting Concept readiness and the complete Target Readiness Set under the frozen Plan. The Set may combine representative criteria and is intentionally smaller than a full mastery assessment; unprobed criteria remain unknown. Independent Evidence is accepted only from the separate, verified, no-assistance Task Attempt. This keeps a potentially easy or guessed diagnostic response from becoming a mastery claim while preserving the Diagnostic's routing value.
