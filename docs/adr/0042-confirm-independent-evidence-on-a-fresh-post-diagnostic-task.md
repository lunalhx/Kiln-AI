# Confirm independent evidence on a fresh post-diagnostic task

A no-hint passing Diagnostic may show that a learner is ready to demonstrate a Target Concept, but it never directly establishes Independent. Kiln-AI will generate a fresh equivalent Independent Test after such a pass and accept Independent Evidence only from that separate, verified, no-assistance Task Attempt. This keeps a potentially easy or guessed diagnostic response from becoming a mastery claim while preserving the Diagnostic's routing value.
