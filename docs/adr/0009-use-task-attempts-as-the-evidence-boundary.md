# Use task attempts as the evidence boundary

Assessment and Learning Evidence will operate on a complete Task Attempt rather than an individual chat message. A Task Attempt binds one learner to one Task Package and records its purpose, every response, source exposure, hint, answer request, and final assessment. Practice may remain multi-turn, but any assistance used anywhere in an Independent Test permanently disqualifies that attempt from independent evidence and converts continued work into practice. In the Phase 0 Apply reference, Diagnostic and Independent Test both permit edits only before one formal submission; that submission closes the attempt. Another formal attempt requires a newly generated equivalent Task Package, preventing answer exposure and repeated editing from being mistaken for mastery.
