# Separate current and highest mastery milestones

Concept Progress will keep both a Current Milestone and a Highest Milestone Reached. The highest value is append-only historical achievement, while the current value may fall from Independent or Durable to Learning when Assessment and Verification agree on a no-hint failure from a valid Independent Test or Delayed Review aligned to the current Mastery Rubric. Assisted practice failures, Teach-back errors, and voluntary requests for help do not by themselves lower the Current Milestone. This preserves honest current guidance without erasing what the learner previously achieved.
