# Separate Apply final-expression and rationale assessment channels

The Apply reference evaluates primary-answer correctness and rationale semantics as separate channels. A deterministic result is never overridden; only `Cannot Decide` invokes isolated Assessment and independent Response Verification, both of which must confirm the primary channel before it passes. Each Diagnostic Task Blueprint either disables rationale or enables the optional corroborated-rationale policy; it never requires rationale. Simple Prerequisite Readiness Checks disable it by default, while Target tasks enable it only when the Task Rubric can distinguish conceptual readiness from an execution slip. When enabled, the learner-facing field explains that it is optional and may help the system interpret an incorrect primary answer. A confirmed-correct primary answer passes that Attempt and ignores rationale. A proven-incorrect primary answer passes through rationale only when both isolated Rationale Assessment and Rationale Sufficiency Verification return Applicable; otherwise it produces the corresponding Conclusive or Unconfirmed Diagnostic Finding under ADR-0075. Independent Test requires a passing primary-answer channel and permits omitted or non-substantive rationale unless a substantive rationale is clearly contradictory. A necessary unresolved channel is Inconclusive Assessment, never learner failure or evidence. Assessment models return only closed judgments and reason codes, with no feedback, evidence, or reasoning.
