# Use one mastery criterion per concept in Phase 0

Phase 0 will keep Concept as the smallest learner-facing unit of state, evidence, and review, and give each Concept exactly one user-readable Mastery Criterion. It will not introduce a separate Learning Objective entity or split Explain, Retrieve, Apply, Teach-back, and Transfer into independently tracked objectives. Broader subjects such as “derivatives” must instead be represented as Topics containing Concepts whose mastery can each be assessed coherently. This keeps confirmation and progress understandable while leaving room to add multidimensional mastery later if real cases require it.
