# Use learner-confirmed canonical mathematical answers

Mathematical Task Attempts will retain the learner's original text, formula-editor structure, or handwritten image, and Assessment will use only a learner-confirmed canonical expression rather than string comparison. Formula-editor submission confirms its authored expression; parsed text and OCR candidates must be rendered for learner confirmation or correction whenever transformed or uncertain. An unconfirmed, unparseable, or ambiguous answer cannot be submitted for Assessment or create Learning Evidence. This lets future OCR and formula-editor adapters evolve without allowing recognition errors to become evidence.
