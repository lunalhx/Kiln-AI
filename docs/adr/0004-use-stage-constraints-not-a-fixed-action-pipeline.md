# Use stage constraints instead of a fixed teaching-action pipeline

Every Learning Flow will preserve the stages Diagnostic, necessary Learning and Practice, Independent Test, and Delayed Review, but Explain, Retrieve, Apply, Teach-back, and Hint are optional Teaching Actions rather than mandatory sequential steps. The Pedagogy Policy selects actions according to the Target Concept's Mastery Criterion and current Learning Evidence; the Router only builds an Execution Plan after that selection. This avoids forcing factual, conceptual, procedural, and argumentative knowledge through the same instructional sequence while keeping independent and delayed verification invariant.
