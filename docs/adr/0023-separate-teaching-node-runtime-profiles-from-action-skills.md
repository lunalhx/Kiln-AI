# Separate Teaching Node runtime Profiles from Action Skills

Each of the five Teaching Node Profiles will be a stable execution sandbox for one Teaching Action, defining permitted Node Context View fields, tool classes, model and Token budgets, base Teaching Result Envelope, retries, validation, tracing, and prohibited state effects. It will not duplicate pedagogical method instructions. Each execution loads exactly one replaceable Action Skill that owns the selected teaching method, action-specific quality rules, examples, and payload-schema contribution; Capability Skills add reusable reasoning or representation techniques, and Subject Skills add terminology, conventions, domain constraints, or tools. Skills cannot broaden the Profile's permissions, replace its base envelope, or gain state-write authority. Profiles therefore control safe execution, while versioned Skills control how pedagogy is performed, allowing teaching methods and new subjects to evolve without graph-runtime changes or duplicated prompts.
