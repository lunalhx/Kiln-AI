# Route primarily by capability rather than subject

Skill routing will primarily match the selected Teaching Node Profile and the Target Concept's Capability Tags, with subject metadata used only as a secondary condition for terminology, conventions, examples, domain constraints, and specialized tools. Capability Tags describe reusable needs such as conceptual, graphical, causal, source-based, or symbolic reasoning and may apply across mathematics, physics, economics, history, and future subjects. Concept preparation proposes these tags from the source and Mastery Criterion; users do not configure Skills, while Phase 0 exposes tags and routing reasons in a developer view. This keeps capabilities reusable and prevents every new subject from requiring a large replacement Skill.
