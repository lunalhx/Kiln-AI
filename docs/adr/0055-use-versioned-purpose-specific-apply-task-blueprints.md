# Use versioned purpose-specific Apply Task Blueprints

The Apply reference uses a frozen `kiln.task-blueprint/v1` as structured execution data. It contains the concept and rubric references, approved source passage IDs, task shape and mathematical scope, notation and answer-representation references, response-field requirement, assessment-policy reference, and novelty policy. Diagnostic and Independent Test share the same Apply Profile and frozen Skill Stack; their separate Blueprints carry the purpose-specific assessment policy and freshness exclusion scope. A Blueprint is not learner-visible text, a Skill, or a model-selected policy.
