# Use one target concept per learning flow

Each Learning Flow will pursue exactly one Target Concept and its Mastery Criterion, and every item of Learning Evidence will be attributed to that Concept alone. Prerequisite and related Concepts may be supplied as Supporting Concepts, but they do not receive state changes from the flow; if one needs teaching or assessment, it starts its own Learning Flow. This avoids ambiguous evidence and state transitions while still allowing the product to lead a learner through several Concepts in sequence.
