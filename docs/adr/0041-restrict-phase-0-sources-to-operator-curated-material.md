# Restrict Phase 0 sources to operator-curated material

Phase 0 Source Ingestion will accept only Curated Sources registered by the operator with known provenance and usage basis. Learner-uploaded, private, and shared materials are out of scope until Kiln-AI has a source-ownership, access-control, retention, deletion, and safety-scanning model. This keeps source grounding auditable without implying that a source is safe to expose merely because it was uploaded.
