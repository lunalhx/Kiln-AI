# Compose small skills with action-owned pedagogy

The Router will compose a Skill Stack instead of selecting a combined subject-and-knowledge-type package. Each execution loads exactly one Action Skill plus at most one Skill in each reasoning, representation, verification, and subject Slot; the Teaching Node Profile remains a thin execution boundary. The Action Skill owns pedagogical behavior, Capability Skills contribute bounded cross-subject methods, and Subject Skills add terminology, conventions, domain constraints, or tools without overriding that behavior. This avoids a subject-by-knowledge-type package explosion and prevents subject extensions from quietly duplicating Explain, Apply, Hint, or other teaching policies.
