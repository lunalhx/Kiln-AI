# Verify every Phase 0 formal Apply task before delivery

Every Phase 0 formal Apply Task Package—including Diagnostic and Independent Test—must pass the deterministic Output Gate, source and Rubric validation, Fingerprint checks, available deterministic verification tools, and one isolated Task Verification model call before learner exposure. This requirement compensates for Phase 0's intentionally model-authored learner task text, before the deferred structured TaskSpec and deterministic task-solver hardening exist. The Task Verifier receives the task, hidden answer, Rubrics, source evidence, and difficulty contract but not the generator's hidden reasoning, and returns only structured judgments for answer correctness, Rubric alignment, source support, difficulty alignment, ambiguity, and issues. It cannot rewrite the package or change workflow state. A Source Gap ends generation immediately. Any invalid Output Gate result, Task Verification rejection, or inconclusive result discards the entire unexposed package and permits exactly one fresh generation cycle; it never repairs a candidate or averages confidence. A second failure returns internal Task Generation Exhausted to the Graph without creating an Attempt or evidence. Task Verification validates the instrument before use and remains separate from Assessment and Verification of the learner's later response.
