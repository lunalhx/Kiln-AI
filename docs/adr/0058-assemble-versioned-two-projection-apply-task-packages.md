# Assemble versioned two-projection Apply Task Packages

The Apply Profile deterministically turns a validated generation draft into `task_package/v1`. Its learner projection contains only locale-rendered task text, deterministic answer fields, legal events, and one-submission rule. Its private assessor projection contains canonical expected-answer facts, Rubric mapping, source trace, equivalence declaration, Profile-derived Fingerprint, and execution trace. The model cannot populate Profile-owned interaction fields, final canonical answer, Fingerprint, or trace. `理由（可选）` is the learner label for the optional rationale field and intentionally does not name a mathematical rule.
