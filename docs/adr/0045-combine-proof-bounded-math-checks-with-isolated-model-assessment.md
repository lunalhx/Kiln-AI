# Combine proof-bounded math checks with isolated model assessment

For mathematical Tasks, a Mathematical Equivalence Check may return only Proven Equivalent, Proven Not Equivalent, or Cannot Decide. A proven result is usable evidence about the final expression, while an unsupported or ambiguous expression must remain Cannot Decide. Assessment and required Verification retain responsibility for complex mathematical and rubric judgment: if the check cannot decide, both isolated model judgments must pass before Independent Evidence is accepted; any disagreement is Inconclusive Assessment. A model cannot override a proven deterministic non-equivalence, and the system never averages confidence or turns evaluator conflict into learner failure.
