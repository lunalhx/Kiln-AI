# Use a neutral transition from Diagnostic to Independent Test

After a passing Diagnostic, Kiln-AI will show only a Neutral Transition before opening the fresh Independent Test. It must not reveal correctness, the answer, missing rules, or other targeted feedback from the Diagnostic. A failing Diagnostic accepts no evidence and ends the Apply-only reference path with the safe result that a later Teaching Profile is required. This prevents cross-attempt feedback from becoming unrecorded assistance before independent evidence.
