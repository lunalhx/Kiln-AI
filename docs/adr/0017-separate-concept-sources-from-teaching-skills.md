# Separate Concept sources from teaching Skills

Concept Preparation will create a versioned Concept Source Pack containing core source excerpts and anchors, Knowledge Base version identities, Concept scope, and retrieval filters. A Teaching Node receives only a bounded core plus additional passages selected under the Execution Plan's action-specific Retrieval Policy; it will not receive the entire Knowledge Base. The Source Pack supplies what claims and tasks are grounded in, while the Skill Stack supplies how the selected Teaching Action reasons, represents, and teaches; course facts will not be copied into Skills, and Skill resolution will not decide factual truth. Each teaching output and Task Package records the source identities, versions, and retrieval query actually used. Models may generate analogies or novel practice settings when identified as generated, but Mastery Criteria, answer correctness, and Assessment claims must be traceable to the Source Pack or a trusted deterministic tool. Missing or conflicting support produces a Source Gap instead of silently substituting untracked model knowledge.
