# Confirm a Concept Contract before the first Learning Flow

Before the first Learning Flow for a selected knowledge-base concept, Concept Preparation will present one concise Concept Contract containing the Concept name, included and excluded scope, one user-readable Mastery Criterion, and source basis. If the selection is too broad to assess coherently, Kiln-AI proposes smaller Concepts and asks the learner to select one rather than introducing multiple Learning Objectives beneath it. Internal Mastery Rubric, Capability Tags, Supporting Concepts, subject metadata, Skill candidates, and generation metadata are prepared but are not part of routine learner confirmation. A confirmed Concept can start or resume flows without repeated confirmation; material changes to its source basis, boundary, or Mastery Criterion create a new contract version and require confirmation. The Concept Contract is a versioned confirmation snapshot, not an additional progress or evidence entity.
